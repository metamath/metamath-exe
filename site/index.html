Metamath-exe

The Metamath proof verifier and proof assistant, ready to run.

The current build → Built from the main line of development, rebuilt and tested whenever anything changes. Run it in your browser, or download one file that runs on Linux, macOS, Windows, and the BSDs.

For a version that never moves under you, every tagged release carries the same two builds, kept at an address that does not change.

This site distributes the program. The Metamath databases it reads, such as set.mm and iset.mm, are maintained separately; get them from us.metamath.org or the set.mm repository.
