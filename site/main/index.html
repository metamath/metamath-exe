Getting it from a script

The button above saves the program under a name carrying its version and commit, which is what you want on a desktop. A script wants the opposite: one address that always gives the current build, whatever it is called. 

curl -fsSLO https://metamath-exe.metamath.org/main/metamath.exe
chmod +x metamath.exe

Both names hold the identical file: metamath.exe and @APE_VERSIONED@ have the same checksum.

Checking what you got

The published checksums are in SHA256SUMS, one line per name:

sha256sum --check --ignore-missing SHA256SUMS

You can also confirm that this exact file was built by this project's CI, from the commit named above, rather than assembled by someone else: 

gh attestation verify metamath.exe --repo metamath/metamath-exe

Running the program does not alter the file, so you can check it whenever you like. The first run does place a small loader in your home directory, which is how one file runs on several operating systems.

Running it

On Windows, run it as it is; elsewhere, chmod +x metamath.exe first. Your system may object: Windows warns about an unrecognized program, and macOS quarantines a file that is not notarized. The README says what to do about both.
